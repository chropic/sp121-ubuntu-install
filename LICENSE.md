# Licensing

Project-authored documentation is intended to be distributed under
`CC-BY-SA-4.0`. Project-authored scripts are intended to be distributed under
`GPL-2.0-or-later`.

Kernel patches retain their original authorship and kernel-compatible licensing.
Third-party files remain under their own licences. A file's SPDX identifier and
original metadata take precedence over this summary.

Before the first public release, the repository will include the complete licence
texts and a per-file SPDX audit. No licence in this repository grants permission
to redistribute proprietary Microsoft or Qualcomm firmware.
